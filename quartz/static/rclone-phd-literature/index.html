rclone-phd-literature

This is a personal, single-user Google Drive integration for synchronizing a research literature folder between a Linux laptop and the owner's Google Drive account.

What it does

The application uses the open-source rclone command-line tool and the Google Drive API to synchronize the folder named PhD Literature. The sync can upload, download, update, and delete files within that configured folder. A separate local-only folder for restricted literature is excluded from synchronization.

Google OAuth currently requests the full Google Drive scope to support bidirectional synchronization of files that may have been added through the Google Drive website. Although that permission is broad, the scheduled synchronization command is configured to operate on the specified literature folder only.

This is not a public service, a multi-user application, or an AI model. It has no public login interface or application backend. It is not affiliated with or endorsed by Google or the rclone project.
