Privacy Policy — rclone-phd-literature

Effective date: 18 November 2026

Purpose and operator

rclone-phd-literature is a personal, single-user OAuth client operated by the owner of the Google account. It enables the open-source rclone program running on the owner's Linux laptop to synchronize the PhD Literature directory with Google Drive.

Google data accessed and how it is used

The application requests the Google Drive scope, which technically permits viewing, creating, modifying, and deleting files across the authorized Drive account. The configured synchronization task uses this access only to list and synchronize files in the designated PhD Literature folder. File names, metadata, file contents, and changes needed for synchronization are processed by rclone on the local device and by Google Drive to deliver the service.

A separate PhD Literature Reserved folder is kept outside the synchronized directory and is not part of the application's configured Google Drive synchronization.

Storage and security

The files selected for synchronization are stored on the owner's laptop and in the owner's Google Drive account. OAuth credentials are stored locally in rclone's configuration file; synchronization state and diagnostic logs may also be stored locally. Transfers between rclone and Google use HTTPS. The application does not operate its own server for collecting or storing document content.

The public information pages do not embed analytics scripts or set application cookies. GitHub Pages and Google may process network and account data under their respective policies.

Sharing, advertising, and AI training

The application does not sell Google user data, use it for advertising, or send synchronized content to AI models. It does not independently share Drive data with other users or services beyond the Google Drive service needed for synchronization. Information received from Google APIs is used in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

Retention and revocation

Files remain in the local directory and Google Drive until the account owner changes or deletes them; bidirectional synchronization may propagate deletions. Local logs and synchronization state are managed on the laptop. The account owner can stop the synchronization service, remove files, and revoke OAuth access at Google Account → Third-party connections. Revoking access prevents further API use but does not automatically remove files already synchronized to either location.

Updates and contact

Changes to this policy will be published on this page with an updated effective date. For questions, use GitHub Issues without disclosing credentials or private document contents.
